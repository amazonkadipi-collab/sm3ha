# Reference design notes

The reference homepage is a compact, utilitarian Arabic RTL layout rather than a pastel editorial landing page. It uses a pale gray/white background, a very small top navigation with the logo aligned to the right, a centered logo image, a single bordered search row with a dark green submit button, then a dark charcoal/green horizontal section header and a long vertical list of text-only search links separated by thin light borders. The page is dense, narrow, and SEO/list oriented. Footer links are simple text links for the brand, contact, and DMCA.

The public routes visible in the reference are `/`, `/trending`, and `/s/{arabic-slug}`. The visible search placeholder is `إبحث عن اغنية او البوم او فنان`; the primary button is `بحث`. The visual direction to reproduce is the structure and density, while using NaghmaHub's original logo, copy, and demo content.
